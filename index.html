Membaca peta

Setiap titik mewakili satu deteksi anomali panas dari pengamatan satelit. Deteksi memerlukan verifikasi lapangan untuk memastikan kebakaran. Angka dalam klaster menunjukkan jumlah pengamatan yang berdekatan pada tingkat zoom tersebut.

Klik klaster untuk memperbesar, atau pilih titik tunggal untuk membaca atributnya. Gunakan kontrol lapisan untuk memilih peta dasar dan menampilkan titik panas.

Menggunakan data sendiri

  1. Di NASA FIRMS, pilih Indonesia, sensor VIIRS, periode pengamatan, dan format CSV. Untuk arsip, masuk dengan Earthdata atau email dan ikuti tautan unduhan.
  2. Pilih Impor data lalu buka file CSV atau GeoJSON Point. Impor mengganti dataset aktif di sesi browser ini.
  3. Kombinasikan filter. Tombol Ekspor CSV mengunduh pengamatan yang lolos filter.
Unduhan NASA FIRMS

Confidence dan FRP

Confidence menyatakan keyakinan algoritme pada deteksi. FRP (fire radiative power) mengukur daya radiasi dalam megawatt. Keduanya perlu ditafsirkan sesuai produk satelit. Satu wilayah dapat teramati berkali-kali.

FAQ FIRMS

Alat peta dan sumber nasional

Aktifkan penggaris, lalu pilih titik awal dan titik akhir untuk mengukur jarak geografis. Lokasi saya memerlukan izin browser. Atlas tersedia lokal, sedangkan ubin OSM dan Esri memerlukan internet.

SiPongi menyediakan pemantauan nasional. Untuk mengimpor datanya, gunakan berkas yang berisi koordinat tiap pengamatan. Cantumkan sumber SIPONGI KEMENHUT.

Buka SiPongi
Hotspot mengindikasikan anomali panas. Konfirmasi kebakaran memerlukan verifikasi lapangan.Sumber pengamatan belum dimuat.

Impor dataset

Pilih CSV pengamatan atau GeoJSON berisi titik. Berkas diproses di browser dan mengganti dataset aktif setelah lolos validasi.

Tarik berkas ke sini

CSV memerlukan latitude, longitude, dan acq_date. Untuk data FIRMS, gunakan tanggal dan waktu UTC.
